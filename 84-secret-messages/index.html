    Pega un mensaje cifrado para leerlo.

    Si la contraseña no es la correcta, AES-GCM no devuelve texto sin sentido: se niega a descifrar porque la etiqueta de autenticación no coincide.

    SHA-256 (hexadecimal)

    Un hash es de un solo sentido: no se puede "descifrar". Cambia una sola letra y el resultado cambia por completo (efecto avalancha). Siempre mide 256 bits = 64 caracteres hexadecimales.
