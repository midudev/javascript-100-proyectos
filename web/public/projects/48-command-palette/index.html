❓ Preguntas frecuentes

¿Por qué usar <dialog> en vez de un div?

Porque el navegador ya gestiona el foco, la tecla Escape, la capa superior (top layer) y la accesibilidad.

¿Qué es aria-activedescendant?

Permite que el foco se quede en el input mientras el lector de pantalla anuncia la opción resaltada.
